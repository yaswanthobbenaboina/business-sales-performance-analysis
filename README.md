Task 1 - Business Sales Performance Analytics

## Objective
Analyze business sales data to identify revenue trends, top products, and regional performance.

## Dataset
Sample Superstore Dataset from Kaggle

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## Key Findings
1. Best Performing Region: West
2. Highest Selling Category: Technology
3. Top Product: Canon imageCLASS 2200 Advanced Copier
4. Loss-Making Sub-Categories: ['Tables', 'Bookcases', 'Supplies']
5. Total Revenue: $2,297,200.86
